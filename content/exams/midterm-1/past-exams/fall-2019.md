## Problem 1 · True/False (20 pts)

> [!question] Problem 1 (20 pts)
> Mark "True" or "False" for the following statements.
> - **(a)** An LSI system specified by the following difference equation: $y[n] - \tfrac12 y[n-1] = x[n]$ can be causal or anti-causal.
> - **(b)** The input and output relationship of an arbitrary system is completely determined by the system's unit pulse response.
> - **(c)** If an LSI system is BIBO unstable, its unit pulse response $h[n]$ must be unbounded.
> - **(d)** Let $h[n] = h_1[n] * h_2[n]$ be the unit pulse response (UPR) of two serial subsystems with UPR $h_1[n]$ and $h_2[n]$. If $h_1$ or $h_2$ is BIBO *unstable*, $h$ must be BIBO *unstable*.
> - **(e)** An LSI system with a finite-length impulse response can be BIBO stable or unstable.
> - **(f)** A time-varying system cannot be causal.
> - **(g)** Let $\sum_{n=-\infty}^{\infty} x[n]\,\delta[2^n u[n] - 8] = 4$. Then, $x[3] = 2$.
> - **(h)** Suppose that the step response $g[n]$ of an LSI system, i.e., the output of the system to the input $x[n] = u[n]$, has a z-transform with a pole at $z = 1/2$. Then, $H(z)$ has also pole at $z = 1/2$.
> - **(i)** If the response $y[n]$ of an LSI system to the input $x[n] = 3^n u[n]$ is unbounded, the system must be BIBO unstable.
> - **(j)** The response $y[n]$ of a BIBO *unstable* LSI system to any non-zero input $x[n]$ is always unbounded.

> [!success]- Solution
> - **(a) True.** The equation fixes $H(z) = \frac{1}{1-\frac12 z^{-1}}$ but not its ROC. $(\frac12)^n u[n]$ and $-(\frac12)^n u[-n-1]$ both satisfy it (key: "we do not know if $y[n]$ or $y[n-1]$ represents the output").
> - **(b) False.** Only LSI systems are determined by $h$: $y = x^2[n]$ and $y = x[n]$ share $h = \delta[n]$.
> - **(c) False.** $h = u[n]$ is bounded and unstable.
> - **(d) False.** $u[n] * (\delta[n]-\delta[n-1]) = \delta[n]$.
> - **(e) False.** An FIR $h$ has a finite $\sum\lvert h\rvert$, so it is always stable.
> - **(f) False.** $y[n] = n\,x[n]$ is time-varying and causal.
> - **(g) False.** $2^n u[n] - 8 = 0$ only at $n = 3$, so the sum is $x[3] = 4$.
> - **(h) True.** $G = H\cdot\frac{1}{1-z^{-1}}$, and the step's factor is finite and nonzero at $z = \frac12$.
> - **(i) False.** The input was already unbounded: $h = \delta[n]$ is stable and returns $3^n u[n]$.
> - **(j) False.** $h = u[n]$ with $x = \delta[n] - \delta[n-1]$ gives $y = \delta[n]$.
>
> Answers: **T F F F F F F T F F.** Each one is explained in the [[exams/midterm-1/true-false-bank|True/False bank]] (Q40, Q3, Q13, Q26, Q41, Q10, Q43, Q32, Q18, Q19).

> [!trap]
> Eight of the ten are False, and each dies to one counterexample: $u[n]$, $\delta[n]$, $\delta[n]-\delta[n-1]$, $y = n\,x[n]$. Keep that kit on your sheet.

## Problem 2 · Classify two systems (12 pts)

> [!question] Problem 2 (12 pts)
> Determine whether the following systems are linear or nonlinear, shift-invariant or shift-varying, and causal or noncausal. *Grading:* Correct answer = +2 pts.; Incorrect answer = −1 pts. No answer = 0 pts.
> - **(a)** $y[n] = x[\lvert n\rvert + n]$
> - **(b)** $y[n] = (0.2)^{\lvert n\rvert}\log[x[n]]$

> [!success]- Solution
> **(a) L, SV, NC.** The system only re-indexes the input: the index is $\lvert n\rvert + n = 2n$ for $n \ge 0$ and $0$ for $n < 0$. Superposition holds (linear). Shifting the input first gives $x[\lvert n\rvert + n - n_0]$, but shifting the output gives $x[\lvert n-n_0\rvert + n - n_0]$, and these differ (shift-varying). $y[1] = x[2]$ is a future sample (noncausal).
>
> **(b) NL, SV, C.** $\log$ is nonlinear ($\log(2x) \ne 2\log x$). The factor $(0.2)^{\lvert n\rvert}$ depends on $n$ (shift-varying). $y[n]$ uses only $x[n]$ (causal, memoryless).
>
> Stability was not asked. (a) is stable (every output sample is an input sample); (b) is not ($\log 0 = -\infty$).

> [!trap]
> For index maps $x[f(n)]$ test causality at **positive** $n$ too: for $n<0$ this system only reads $x[0]$, which looks harmless, but $y[1] = x[2]$. More rows like these: [[exams/midterm-1/system-property-bank|system-property bank]].

> [!success]- Solution
> **(a)** $x[n] = 2\delta[n-2]$, so $y[n] = (x*h)[n] = 2h[n-2]$ and $h[n] = \tfrac12\,y[n+2]$:
> $$
> \boxed{h[n] = \tfrac12\delta[n+1] + \delta[n] + \tfrac12\delta[n-1] = \{\tfrac12,\ \underset{\uparrow}{1},\ \tfrac12\}}
> $$
> In the z-domain: $H = \dfrac{Y}{X} = \dfrac{z^{-1}+2z^{-2}+z^{-3}}{2z^{-2}} = \tfrac12 z + 1 + \tfrac12 z^{-1}$.
>
> **(b)** $s[n] = u[n]*h[n] = \tfrac12 u[n+1] + u[n] + \tfrac12 u[n-1]$, so
> $$
> s[-1] = \tfrac12,\quad s[0] = \tfrac32,\quad s[1] = 2,\quad s[2] = 2.
> $$
>
> **(c)** **Not causal:** $h[-1] = \tfrac12 \ne 0$. For example, $y[-1]$ depends on $x[0]$.

> [!trap]
> Do not forget the shift. Writing $h = \frac12 y[n]$ drops it and gives a causal-looking $h = \frac12\delta[n-1] + \delta[n-2] + \frac12\delta[n-3]$, which makes (a), (b) and (c) all wrong. The input sits at $n = 2$, so move $y$ **left** by 2.

## Problem 4 · Finite convolution (5 pts)

> [!question] Problem 4 (5 pts)
> Calculate the result of the following convolution $\{\underset{\uparrow}{1}, -4, 2, -1, 3, 1\} * \{\underset{\uparrow}{-1}, 1, -1\}$.

> [!success]- Solution
> Both sequences start at $n = 0$, so $y$ starts at $n = 0$ and has $6 + 3 - 1 = 8$ samples. The key uses the matrix form $y = \mathbf{H}x$, an $8\times3$ matrix whose columns are shifted copies of $x$, times $(-1, 1, -1)^T$:
> $$
> \boxed{y[n] = \{\underset{\uparrow}{-1},\ 5,\ -7,\ 7,\ -6,\ 3,\ -2,\ -1\}}\quad(n = 0,\dots,7).
> $$
> Check: $\sum y = -2 = (\sum x)(\sum h) = 2\cdot(-1)$.

> [!note] Where is $n = 0$?
> Both arrows in the statement sit under the **first** entries ($1$ and $-1$), so the output starts at $n = 0$. The key labels the first row of its matrix "$n = 0$" and puts the final arrow under the first entry, $-1$. Both are consistent with the statement.

> [!trap]
> Read the arrows before anything else. Had the arrow of $h$ been under its middle entry, every index would move by one, with the same numbers. The sum check catches arithmetic slips but not index slips.

## Problem 5 · z-transforms of finite-length signals (10 pts)

> [!question] Problem 5 (10 pts)
> Calculate the z-transform and corresponding ROC of the following functions:
> - **(a)** $x[n] = 3^{-n}\left(u[n-5] - u[n-100]\right)$
> - **(b)** $x[n] = e^{-n^2}\,u[n-8]\,u[-n+10]$

> [!success]- Solution
> **(a)** $u[n-5]-u[n-100]$ is 1 for $5 \le n \le 99$ (95 samples). A geometric sum with ratio $\frac13 z^{-1}$:
> $$
> X(z) = \sum_{n=5}^{99}\left(\tfrac13 z^{-1}\right)^n = \boxed{\frac{(\frac13)^5 z^{-5}\left(1 - (\frac13)^{95}z^{-95}\right)}{1 - \frac13 z^{-1}},\qquad z \ne 0}
> $$
> The key stops at $\sum_{k=5}^{99}(\frac13)^k z^{-k}$, $z \ne 0$. Since "calculate" asks for a closed form, finish the geometric sum. The denominator's apparent pole at $z = \frac13$ is cancelled by the numerator, which also vanishes there: $x$ has finite length, so the ROC is everything except $z = 0$.
>
> **(b)** $u[n-8]\,u[-n+10] = 1$ exactly for $n = 8, 9, 10$:
> $$
> \boxed{X(z) = e^{-64}z^{-8} + e^{-81}z^{-9} + e^{-100}z^{-10},\qquad z \ne 0}
> $$

> [!warning] Answer-key erratum (#5b)
> The handwritten key writes $e^{-91}z^{-9}$ for the middle term; $9^2 = 81$, so it is $e^{-81}z^{-9}$. It also labels the answer $X_d(\omega)$, but this is the z-transform $X(z)$ (ROC $z \ne 0$), not a DTFT. Listed on [[0-toolkit/05-errata|Errata]].

> [!trap]
> - $u[n-100]$ switches on **at** 100, so the last sample is $n = 99$. $u[-n+10]$ is 1 for $n \le 10$.
> - The ROC of a finite-length signal is the whole plane except possibly $0$ and/or $\infty$. Do not answer "$\lvert z\rvert > \frac13$" because of the closed form's denominator.

## Problem 6 · Inverse z-transform (6 pts)

> [!question] Problem 6 (6 pts)
> Calculate the inverse z-transform for
> $$
> Y(z) = 1 + z^{-100} + \frac{1}{1-5z^{-1}},\qquad \text{ROC: } \lvert z\rvert > 5.
> $$

> [!success]- Solution
> Term by term, with the right-sided pair for $\lvert z\rvert > 5$:
> $$
> \boxed{y[n] = \delta[n] + \delta[n-100] + 5^n u[n]}
> $$

> [!trap]
> $z^{-100}$ is a **delay**, $\delta[n-100]$, not $\delta[n+100]$. The ROC decides $5^n u[n]$ (right-sided) versus $-5^n u[-n-1]$.

## Problem 7 · All valid ROCs (15 pts)

> [!question] Problem 7 (15 pts)
> The z-transform of $x[n]$ is given below:
> $$
> X(z) = \frac{z}{z - e^{j\frac{\pi}{3}}} + \frac{z}{z - 0.5}.
> $$
> Determine all the valid ROCs of $X(z)$ and for each case, calculate the inverse z-transform.

> [!success]- Solution
> $X(z) = \dfrac{1}{1-e^{j\pi/3}z^{-1}} + \dfrac{1}{1-\frac12 z^{-1}}$, with poles of magnitude $1$ and $\tfrac12$. The valid ROCs are the three rings those magnitudes cut the plane into:
>
> | ROC | $x[n]$ |
> |---|---|
> | $\lvert z\rvert > 1$ | $e^{j\pi n/3}u[n] + (\tfrac12)^n u[n]$ (both right-sided) |
> | $\tfrac12 < \lvert z\rvert < 1$ | $-e^{j\pi n/3}u[-n-1] + (\tfrac12)^n u[n]$ |
> | $\lvert z\rvert < \tfrac12$ | $-e^{j\pi n/3}u[-n-1] - (\tfrac12)^n u[-n-1]$ (both left-sided) |
>
> The fourth combination (the $e^{j\pi/3}$ term right-sided and the $\frac12$ term left-sided) would need $\lvert z\rvert > 1$ and $\lvert z\rvert < \frac12$ at once, so its ROC is empty (the key's "Case 4").

> [!trap]
> - The ROC boundaries are the pole **magnitudes** ($1$ and $\frac12$). The angle $\frac\pi3$ plays no role.
> - Left-sided pairs carry a minus sign: $\dfrac{1}{1-pz^{-1}} \leftrightarrow -p^n u[-n-1]$ for $\lvert z\rvert < \lvert p\rvert$.
> - $N$ poles with distinct magnitudes give $N+1$ valid ROCs, not $2^N$.

## Problem 10 · Causal $H(z)$, stability, LCCDE, a cancelling cascade (12 pts)

> [!question] Problem 10 (12 pts)
> Consider a *causal* LSI system with transfer function
> $$
> H(z) = \frac{1-2z^{-1}}{(1-\frac12 z^{-1})(1-\frac14 z^{-1})}.
> $$
> - **(a)** What is the ROC of $H(z)$?
> - **(b)** Is the system BIBO stable? Justify your answer.
> - **(c)** Find the difference equation (or LCCDE) for this system.
> - **(d)** **True or False:** If the previous system is serially connected to an unstable LSI system with impulse response $\tilde h[n] = 2^n u[n]$, then the overall system is BIBO unstable. Justify your answer.

> [!success]- Solution
> **(a)** Poles at $\frac12$ and $\frac14$, causal: **ROC $\lvert z\rvert > \tfrac12$**.
>
> **(b)** **Yes**, because the ROC contains the unit circle $\lvert z\rvert = 1$. (The zero at $z = 2$ lies outside the unit circle, and zeros do not matter for stability.)
>
> **(c)** $Y(z)\left(1 - \frac34 z^{-1} + \frac18 z^{-2}\right) = X(z)\left(1 - 2z^{-1}\right)$, so
> $$
> \boxed{y[n] = \tfrac34\,y[n-1] - \tfrac18\,y[n-2] + x[n] - 2x[n-1]}
> $$
>
> **(d)** **False.** $\tilde H(z) = \dfrac{1}{1-2z^{-1}}$, and its pole at $z = 2$ is cancelled by the zero of $H$:
> $$
> H(z)\tilde H(z) = \frac{1}{(1-\frac12 z^{-1})(1-\frac14 z^{-1})},\qquad \lvert z\rvert > \tfrac12,
> $$
> which is stable. This is pole–zero cancellation.
>
> (This is the same $H(z)$ as [[exams/midterm-1/past-exams/spring-2023|SP2023 #6]], where $h[n] = -6(\frac12)^n u[n] + 7(\frac14)^n u[n]$.)

> [!trap]
> - (c) The signs flip when the denominator's terms move to the right-hand side: $-\frac34 z^{-1} \to +\frac34 y[n-1]$ and $+\frac18 z^{-2} \to -\frac18 y[n-2]$.
> - (d) "Unstable part ⇒ unstable whole" is the classic False. Multiply the transfer functions and look for cancellation before deciding. The same pattern appears in [[problems/unbounded-outputs-and-pole-matching|pole matching]].
