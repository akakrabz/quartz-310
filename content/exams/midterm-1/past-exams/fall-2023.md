## Problem 1 · True/False (12 pts)

> [!question] Problem 1
> Select **True** or **False** for each statement.
>
> (a) Any causal discrete-time system must also be time-invariant.
>
> (b) The ROC of a given z-transform cannot contain any poles or zeros.
>
> (c) Two BIBO stable systems connected in parallel always form a BIBO stable system.
>
> (d) For a discrete-time system with impulse response $h[n]$, the system output $y[n]$ to any input signal $x[n]$ is always given by $y[n] = x[n]*h[n]$.
>
> (e) Two LTI systems given by impulse responses $h_1[n]$ and $h_2[n]$ are connected in series in some order, i.e. $h_1[n]$ or $h_2[n]$ may come first. If we pass an input signal $x[n]$ to this system, we will receive the same output signal $y[n]$ for either ordering of $h_1[n]$ and $h_2[n]$.
>
> (f) A BIBO stable LTI system with transfer function $H(z) = \dfrac{1}{1 - 3z^{-1}}$ must be non-causal.

> [!success]- Solution 1
> - **(a) False.** $y[n] = n\,x[n]$ is causal (memoryless) but time-varying.
> - **(b) False.** An ROC never contains a pole, but it can contain zeros: $X(z) = 1 - z^{-1}$ has ROC $z \ne 0$, which contains its zero at $z = 1$.
> - **(c) True.** $\lvert y_1\rvert \le B_1$ and $\lvert y_2\rvert \le B_2$ give $\lvert y_1 + y_2\rvert \le B_1 + B_2$ — true even for systems that are not LTI.
> - **(d) False.** Convolution with $h$ describes LTI systems only.
> - **(e) True.** $x * h_1 * h_2 = x * h_2 * h_1$: convolution is commutative and associative.
> - **(f) True.** Pole at $3$; stability forces ROC $\lvert z\rvert < 3$, so $h = -3^n u[-n-1]$ — anti-causal, hence non-causal.

> [!trap] Where points go
> - **(b)** is half true — the "or zeros" part makes it False. Read every word of a T/F statement.
> - **(e)** is True for **LTI** systems; for non-LTI blocks the order can matter.

## Problem 2 · System properties (12 pts)

> [!question] Problem 2
> For each system, indicate "yes" or "no" for Linear, Time-invariant, Causal, Stable (only the answers in the boxes are graded).
>
> 1. $y[n] = \log(\lvert n\rvert + 1)\,x[n]$
> 2. $y[n] = x[n] * u[n+1]$
> 3. $y[n] = x[n] + 3$

> [!success]- Solution 2
>
> | system | Linear | Time-inv. | Causal | Stable |
> |---|---|---|---|---|
> | $\log(\lvert n\rvert+1)\,x[n]$ | **Yes** | **No** | **Yes** | **No** |
> | $x[n]*u[n+1]$ | **Yes** | **Yes** | **No** | **No** |
> | $x[n]+3$ | **No** | **Yes** | **Yes** | **Yes** |
>
> - Row 1: time-varying gain ⇒ linear, not TI; memoryless ⇒ causal; $x = 1$ gives $y = \log(\lvert n\rvert + 1) \to \infty$ ⇒ unstable.
> - Row 2: LTI with $h = u[n+1]$; $h[-1] = 1 \ne 0$ ⇒ non-causal; $\sum\lvert h\rvert = \infty$ ⇒ unstable.
> - Row 3: $x = 0$ gives $y = 3$ ⇒ not linear (affine); TI, causal, $\lvert y\rvert \le B + 3$.

> [!trap] Where points go
> - **Row 1:** the gain grows only *logarithmically*, but it is still unbounded — slow growth is still growth.
> - **Row 3:** "$+3$" is the textbook non-linear system (zero in, nonzero out). More rows: [[exams/midterm-1/system-property-bank|system-property bank]].

## Problem 3 · Convolution (12 pts)

> [!question] Problem 3
> Calculate $y[n] = x[n]*h[n]$.
>
> (a) $\{x[n]\}_{n=0}^{4} = \{\underset{\uparrow}{1},\ 2,\ 3,\ 2,\ 1\}$, $\quad \{h[n]\}_{n=0}^{1} = \{\underset{\uparrow}{-1},\ 1\}$
>
> (b) $x[n] = \left(\tfrac34\right)^n u[n]$, $\quad h[n] = 2u[n] - u[n-1] - u[n-2]$

> [!success]- Solution 3
> **(a)** $h = -\delta[n] + \delta[n-1]$, so $y[n] = x[n-1] - x[n]$ (a negated first difference), $n = 0,\dots,5$:
> $$
> \boldsymbol{y[n] = \{\underset{\uparrow}{-1},\ -1,\ -1,\ 1,\ 1,\ 1\}}
> $$
> **(b)** Simplify $h$ first: it equals $2$ at $n = 0$, $2 - 1 = 1$ at $n = 1$, and $2 - 1 - 1 = 0$ for $n \ge 2$, so $h = 2\delta[n] + \delta[n-1]$:
> $$
> \boldsymbol{y[n] = 2\left(\tfrac34\right)^n u[n] + \left(\tfrac34\right)^{n-1}u[n-1]}
> $$

> [!trap] Where points go
> - **(b)** Convolving with each step separately (three infinite convolutions) instead of noticing that $h$ is a 2-tap FIR. Always evaluate a sum of steps at a few $n$ first.
> - The delayed copy needs its own $u[n-1]$.

## Problem 4 · Which $h$? (5 pts)

> [!question] Problem 4
> An LTI system with impulse response $h[n]$ responds to $x[n] = u[n]$ with $y[n] = \delta[n] + \delta[n-1]$. Which sequence is $h[n]$? (Circle one)
>
> (a) $\{\underset{\uparrow}{1},\ 0,\ 1\}$ · (b) $\{\underset{\uparrow}{1},\ 0,\ -1\}$ · (c) $\{\underset{\uparrow}{1},\ 1\}$ · (d) $\{\underset{\uparrow}{1},\ -1\}$

> [!success]- Solution 4
> $\delta[n] = u[n] - u[n-1]$, so by LTI the impulse response is the step response minus its delay: $h[n] = s[n] - s[n-1] = \delta[n] + \delta[n-1] - \delta[n-1] - \delta[n-2] = \delta[n] - \delta[n-2]$.
>
> **Answer (b): $h[n] = \{\underset{\uparrow}{1},\ 0,\ -1\}$.** (Check: $u[n] - u[n-2] = \delta[n] + \delta[n-1]$ ✓.)

> [!trap] Where points go
> Picking (c) because the *output* is $\{1, 1\}$ — that is the step response, not $h$. Recipe: [[problems/finding-h-from-input-output-pairs|finding h from input–output pairs]].

## Problem 5 · z-transform of $n\,u[n+1]$ (9 pts)

> [!question] Problem 5
> Calculate the z-transform $X(z)$ of $x[n] = n\,u[n+1]$.

> [!success]- Solution 5
> The only nonzero sample at negative time is $x[-1] = -1$ (and $x[0] = 0$), so $x[n] = -\delta[n+1] + n\,u[n]$:
> $$
> \begin{aligned}
> \boldsymbol{X(z)} &\boldsymbol{= -z + \frac{z^{-1}}{(1-z^{-1})^2} = \frac{1}{(1-z^{-1})^2} - \frac{z}{1-z^{-1}}}\\[4pt]
> &\boldsymbol{= \frac{-z(1-2z^{-1})}{(1-z^{-1})^2},\qquad 1 < \lvert z\rvert < \infty}
> \end{aligned}
> $$
> (The key's routes: $n\,u[n+1] = (n+1)u[n+1] - u[n+1]$ with shift + differentiation, or $X = -z\,\frac{d}{dz}\frac{z}{1-z^{-1}}$.)

> [!trap] Where points go
> - Dropping the upper ROC limit: the sample at $n = -1$ puts a $z^{+1}$ term in $X$, so $z = \infty$ is **excluded**.
> - Applying the time-shift property to $n$ as well as to $u$: $n\,u[n+1]$ is not "$n\,u[n]$ advanced by 1" (that would be $(n+1)u[n+1]$).

## Problem 6 · All possible ROCs (20 pts)

> [!question] Problem 6
> An LTI system has transfer function
> $$
> H(z) = \frac{1 - z^{-1}}{\left(1 - \frac12 z^{-1}\right)\left(1 - 2z^{-1}\right)} .
> $$
> (a) Determine all possible ROCs and the corresponding impulse response $h[n]$ for each ROC.
>
> (b) Determine the corresponding difference equation.

> [!success]- Solution 6(a)
> Cover-up: $A_1 = \left.\dfrac{1-z^{-1}}{1-2z^{-1}}\right|_{z=1/2} = \dfrac{-1}{-3} = \tfrac13$, $\;A_2 = \left.\dfrac{1-z^{-1}}{1-\frac12 z^{-1}}\right|_{z=2} = \dfrac{1/2}{3/4} = \tfrac23$, so $H = \dfrac{1/3}{1-\frac12 z^{-1}} + \dfrac{2/3}{1-2z^{-1}}$.
>
> | ROC | pole $\tfrac12$ term | pole $2$ term | $h[n]$ | system |
> |---|---|---|---|---|
> | $\lvert z\rvert > 2$ | right | right | $\tfrac13(\tfrac12)^n u[n] + \tfrac23\,2^n u[n]$ | causal, unstable |
> | $\lvert z\rvert < \tfrac12$ | left | left | $-\tfrac13(\tfrac12)^n u[-n-1] - \tfrac23\,2^n u[-n-1]$ | anti-causal, unstable |
> | $\tfrac12 < \lvert z\rvert < 2$ | right | left | $\tfrac13(\tfrac12)^n u[n] - \tfrac23\,2^n u[-n-1]$ | two-sided, **stable** |
>
> The fourth combination (pole $\tfrac12$ left-sided, pole $2$ right-sided) needs $\lvert z\rvert < \tfrac12$ **and** $\lvert z\rvert > 2$: empty, so it is not an ROC.

> [!success]- Solution 6(b)
> $\left(1 - \tfrac12 z^{-1}\right)\left(1 - 2z^{-1}\right) = 1 - \tfrac52 z^{-1} + z^{-2}$:
> $$
> \boldsymbol{y[n] - \tfrac52\,y[n-1] + y[n-2] = x[n] - x[n-1]}
> $$
> (The same difference equation for all three ROCs — the LCCDE alone does not fix causality.)

> [!trap] Where points go
> - Listing four ROCs, or listing the empty one. Two poles give **three** rings: outside, inside, between.
> - The minus sign on every left-sided term. See [[problems/all-possible-rocs|all possible ROCs]].

## Problem 7 · Causal system with a pole on the unit circle (20 pts)

> [!question] Problem 7
> A **causal** LTI system has
> $$
> H(z) = \frac{1 - 3z^{-1} + 2z^{-2}}{1 + \frac34 z^{-1} - \frac14 z^{-2}} .
> $$
> (a) Determine the poles, zeros, and ROC of the system.
>
> (b) Calculate the system response $y[n]$ to the input $x[n] = u[n]$.
>
> (c) Is the system BIBO stable? If not, give an example of a bounded input that will produce an unbounded output.

> [!success]- Solution 7(a)
> $$
> H(z) = \frac{(1-2z^{-1})(1-z^{-1})}{(1-\frac14 z^{-1})(1+z^{-1})}
> $$
> **Poles $z = \tfrac14,\ -1$; zeros $z = 1,\ 2$; ROC $\lvert z\rvert > 1$** (causal ⇒ outside the outermost pole, $\lvert -1\rvert = 1$).

> [!success]- Solution 7(b)
> $X(z) = \dfrac{1}{1-z^{-1}}$ cancels the zero at $z = 1$:
> $$
> Y(z) = \frac{1 - 2z^{-1}}{(1-\frac14 z^{-1})(1+z^{-1})} = \frac{-7/5}{1-\frac14 z^{-1}} + \frac{12/5}{1+z^{-1}},\qquad \lvert z\rvert > 1
> $$
> ($A_1 = \frac{1-8}{1+4} = -\frac75$ at $z = \tfrac14$; $A_2 = \frac{1+2}{1+\frac14} = \frac{12}{5}$ at $z = -1$.)
> $$
> \boldsymbol{y[n] = -\tfrac75\left(\tfrac14\right)^n u[n] + \tfrac{12}{5}(-1)^n u[n]}
> $$

> [!success]- Solution 7(c)
> **Not BIBO stable**: the pole at $z = -1$ lies on the unit circle, so the ROC $\lvert z\rvert > 1$ does not contain it. A bounded input that resonates with it: $\boldsymbol{x[n] = (-1)^n u[n] = \cos(\pi n)u[n]}$ — it creates a double pole at $-1$, and $y$ grows like $n$.

> [!trap] Where points go
> - **(c)** "The step response in (b) is bounded, so the system is stable" — no: stability is about **every** bounded input. The step happened to hit the zero at 1, not the pole at $-1$.
> - **(a)** A causal ROC with a unit-circle pole is $\lvert z\rvert > 1$, which *excludes* the circle — that is exactly why it is unstable ([[concepts/marginal-stability|marginal stability]]).

```python
import numpy as np
from scipy.signal import lfilter
b, a = [1, -3, 2], [1, 3/4, -1/4]            # causal H(z), FA2023 #7
n = np.arange(8)
y = lfilter(b, a, np.ones(8))                # response to u[n]
print(np.allclose(y, -7/5*(1/4)**n + 12/5*(-1.0)**n))
yy = lfilter(b, a, (-1.0)**np.arange(4000))  # bounded input (-1)^n u[n]
print(round(abs(yy[999]), 1), round(abs(yy[3999]), 1))   # grows like n
```

```text
True
4795.4 19195.4
```

## Problem 8 · Stability parameter, causal vs two-sided (10 pts)

> [!question] Problem 8
> An LTI system is described by
> $$
> y[n] - \tfrac23\,y[n-1] - \tfrac89\,y[n-2] = 3x[n] + \alpha\,x[n-1],
> $$
> where $\alpha$ is a finite, real-valued constant and a transfer function $H(z)$ exists for the system.
>
> (a) Assuming the system is **causal**, for what value(s) of $\alpha$ is it BIBO stable?
>
> (b) Assuming the system is **non-causal** and **two-sided**, for what value(s) of $\alpha$ is this non-causal system BIBO stable?

> [!success]- Solution 8
> $1 - \tfrac23 z^{-1} - \tfrac89 z^{-2} = \left(1 - \tfrac43 z^{-1}\right)\left(1 + \tfrac23 z^{-1}\right)$, so
> $$
> H(z) = \frac{3 + \alpha z^{-1}}{\left(1 - \frac43 z^{-1}\right)\left(1 + \frac23 z^{-1}\right)},\qquad \text{poles } \tfrac43,\ -\tfrac23;\ \text{zero } z = -\tfrac{\alpha}{3}.
> $$
> **(a)** Causal ⇒ ROC $\lvert z\rvert > \tfrac43$, unstable unless the zero cancels the pole at $\tfrac43$: $-\tfrac{\alpha}{3} = \tfrac43$, i.e. $\boldsymbol{\alpha = -4}$ (then $H = \dfrac{3}{1+\frac23 z^{-1}}$, $\lvert z\rvert > \tfrac23$).
>
> **(b)** Two-sided ⇒ ROC $\tfrac23 < \lvert z\rvert < \tfrac43$ (the other two-sided combination is empty). It contains the unit circle, so the system is stable **for all values of $\alpha$**. (Strictly, for every $\alpha$ that leaves both poles in place: $\alpha = -4$ or $\alpha = 2$ cancels one pole, and then no two-sided version exists.)

> [!trap] Where points go
> - Answering (b) with the same $\alpha = -4$: once the ROC is the annulus, the pole at $\tfrac43$ is harmless — nothing needs cancelling.
> - Getting the zero wrong: $3 + \alpha z^{-1} = 0$ at $z = -\alpha/3$, not $z = -\alpha$. Recipe: [[problems/parameters-for-stability|parameters for stability]].
